Gerar convite

Informe os dados iniciais do aluno. O sistema cria ou atualiza o cadastro como pendente e monta o link para conclusão.

Como usar

Fluxo ideal para o administrativo.

1. Preencha os dados iniciais Digite pelo menos o e-mail do aluno para gerar o convite com segurança.
2. Gere o link O sistema cria o acesso e prepara atalhos para copiar ou encaminhar.
3. Envie ao aluno Compartilhe por WhatsApp, Telegram, SMS ou e-mail, conforme sua necessidade.
4. Acompanhe o cadastro Depois, acompanhe a evolução do aluno pela gestão de alunos.
